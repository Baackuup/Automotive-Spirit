# Automotive Spirit

**Automotive Spirit** is a reference guide to the car brands of the world.

The site covers 129 brands from 21 countries and the groups that own them. For each brand, it lists the
models with every generation: production years, engines, power, dimensions and photos.

**Website:** https://baackuup.github.io/Automotive-Spirit/
