Mercedes-Benz W142

Mercedes-Benz · Germany

1937–1942

Abstract

The Mercedes-Benz W142 is a large luxury car, built 1937–1942 in Germany: Stuttgart. Body styles: 320 N (short wheelbase):, 3-seater Cabriolet, Coupé with removable roof, 320 (regular wheelbase):, 4-door Limousine (saloon), 4-door Pullman-Limousine ("six-light" saloon/sedan). Layout: FR layout.
